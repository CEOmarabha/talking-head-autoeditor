AutoEditor Helper

Runs video edits on this computer.

Checking

Finish one-time setup

About 10 to 20 minutes. AutoEditor checks every key for you. Keys are encrypted by this computer and are never shown in the activity log.

Want the fastest setup? DeepSeek is required on the website. Pexels, Pixabay, and ElevenLabs can be skipped if signup feels like too much. The related resource will be unavailable. HyperFrames and Remotion stay on for every edit, and Remotion asks you to choose the license that applies to you. You can change these choices later. The yellow Help button on the website can walk you through any step.

1. Connect this computer

On the AutoEditor website, copy your Setup code and paste it here.

2. Pexels stock video

Connect a free Pexels account for automatic stock footage, or skip it. If skipped, AutoEditor will not receive anything from Pexels.

  1. Press .
  2. Create an account with your email, Google, or Apple login.
  3. Verify your email if Pexels asks.
  4. Press .
  5. Choose Get Started or Your API Key. Describe the app as “personal video editing.”
  6. Copy the API key and paste it below.
3. Pixabay stock video

Connect a free Pixabay account for a second stock source, or skip it. If skipped, AutoEditor will not receive anything from Pixabay.

  1. Press .
  2. Create an account and finish any email confirmation.
  3. Press .
  4. Make sure you are signed in. Your API key appears next to the required key field.
  5. Copy that key and paste it below.
4. ElevenLabs sound effects

Connect an ElevenLabs account for generated sound effects, or skip it. If skipped, AutoEditor uses only its built-in sound effects.

  1. Press .
  2. Create a free account and finish any email confirmation.
  3. Press .
  4. Select Create API Key. Name it “AutoEditor.”
  5. Turn on restrictions, allow Sound Effects, and set a small credit limit. Do not add an IP restriction because this app runs from your own computer.
  6. Create the key, copy it once, and paste it below. You can read the before continuing.
5. Remotion animated visuals

HyperFrames needs no account and is already included. For Remotion, choose the one statement that is true for you.

  1. Read the .
  2. Open the and purchase the plan that applies to your organization.
  3. Open License keys, create or copy the public rendering key, then paste it below.

Checking connected accounts, then rendering a tiny HyperFrames and Remotion test. This can take a few minutes the first time.
