Step 1: connect DeepSeek

AutoEditor uses DeepSeek (an AI) to do the editing. You bring your own DeepSeek key so it's your account, not shared. It costs a few cents per video. Paste your key below to unlock everything.

Don't have a key yet? Do this first (5 min)
  1. Open platform.deepseek.com and make a free account (email + password).
  2. Add a little credit: click Top up (or "Billing") and add $5. That's enough for dozens of videos.
  3. Click API keys in the left menu, then Create new API key. Give it any name.
  4. It shows the key once — click Copy. (It starts with sk-.)
  5. Come back here, paste it in the box above, and press Check & unlock.

Tip: keep that DeepSeek tab open until you've pasted the key here — you can't see it again later.

The moment your key works, a yellow Help button appears in the corner — a built-in assistant that can walk you through anything from there on.

    One-time: set up your Helper

    Your own computer does the video rendering, so there's a small free Helper to set up once. You only do this the first time.

    1. Download the Helper for your computer:
      Download AutoEditor Helper
    2. Unzip it (double-click the downloaded file), then open the Start Helper file inside: on Windows double-click start-helper.bat; on Mac double-click start-helper.command.
    3. The first time, it may ask to install a couple of free tools (Python and FFmpeg) — say yes and let it finish.
    4. When it asks, paste your Setup code (below) and press Enter. Leave that little window open while you make a video.
