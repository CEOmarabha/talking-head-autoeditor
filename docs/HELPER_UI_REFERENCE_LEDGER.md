# AutoEditor Helper UI reference ledger

Primary device is a normal Windows laptop. Mac is supported at parity. The
mode is Operate: a friend must connect the machine and reach one successful
render without learning developer tooling.

## Reference direction

1. Windows app installation and security prompts. Keep the install path native,
   show the verified publisher, never teach a friend to bypass SmartScreen on a
   final release, and use Start menu plus desktop shortcuts.
   https://support.microsoft.com/windows/protect-your-pc-from-potentially-unwanted-applications-c7668a25-174e-3b78-0191-faf0607f7a6e
2. Apple Developer ID and notarized outside-App-Store distribution. Use a DMG,
   Applications install, normal double-click launch, and no Gatekeeper bypass
   in the final friend guide.
   https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution
3. 1Password’s desktop onboarding pattern. Explain why a secret is needed at
   the point of entry, keep it masked, store it with OS protection, validate it
   immediately, and give a precise recovery action.
   https://support.1password.com/getting-started-mac/
4. Omar's Stylish Cuts reference system. Keep one strong editorial premise,
   fine rules, restrained motion, obvious action, and real operational copy.
   Reject decorative metrics, glass effects, component dumping, and motion
   without a job. Reviewed from `CEOmarabha/stylishbarbers-cloudflare`.
5. Omar Command Center. Keep the disciplined dark work surface, small
   monospaced labels, high-contrast state colors, and clear information
   density. Reject its collectible-card effects because account setup is a
   utility task. Reviewed from `CEOmarabha/omar-command-center`.
6. Mavericks verification contract. Keep 44-pixel controls, visible focus,
   reduced-motion support, real viewport testing, factual copy, and a
   screenshot-backed handoff. Reviewed from
   `CEOmarabha/mavericks-trucking`.

## Chosen direction

An editorial production console built from coal black, warm ivory, and aged
brass. Fine rules and compact monospaced labels create hierarchy without fake
dashboard chrome. The website and Helper use the same visual grammar. Setup is
one scrollable document instead of a wizard with hidden future steps. Each
account section says what the source provides, how to create the account, and
exactly what happens if it is skipped. The primary action appears once after
all choices. Runtime checks remain visible as evidence, not decoration.

## Ten-lens check

- Interface: “Finish one-time setup” and the current readiness state are
  understood immediately.
- System: numbered fieldsets, ivory copy, brass action, green available,
  amber skipped, and red failed.
- Motion: only short hover and press feedback. Account creation already
  crosses browser and app boundaries.
- Creative code: none.
- Atmosphere: private production suite, serious and calm.
- Material: coal surfaces, precise dividers, and aged-brass registration marks.
- Image: no image earns space in a credential setup flow.
- Symbols: words plus check marks in status output; no decorative icon row.
- Typography: Segoe UI Variable and Aptos are intentional on Windows. The
  system-font path keeps text native, sharp, and offline. Compact Cascadia Mono
  labels provide the production-console voice without becoming decoration.
- Mobile: the Helper is desktop-only; the website download and Setup-code flow
  still wrap cleanly on a narrow browser.
