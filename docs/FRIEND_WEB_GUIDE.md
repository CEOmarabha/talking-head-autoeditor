# AutoEditor friend guide

Use [FRIEND_SETUP.md](FRIEND_SETUP.md) as the one friend-facing guide. It
covers the signed Windows and Mac installers, DeepSeek, Pexels, Pixabay, and
ElevenLabs setup or Skip choices, Remotion licensing, HyperFrames, first edit, revision chat,
storage, deletion, and troubleshooting.

The old terminal, Python, FFmpeg, ZIP, `.bat`, and `.command` setup is a legacy
developer path. Do not send it to friends.
