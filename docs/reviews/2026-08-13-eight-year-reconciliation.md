# GPT-5.6 Sol Ultra and Fable 5 MAX Reconciliation

Date: 2026-08-13

Both models received the same brief and were told to argue. Sol worked as an
independent reviewer without repository access. Fable answered from the Claude
desktop session that had previously run the 0.1.1 Mac acceptance loop. The
model picker showed Fable 5 Max.

## Shared Conclusions

Both reviews supported these decisions:

- preserve RAW and source clock mapping before investing in a larger semantic
  program;
- preserve approved intent and draft state so an unfinished project can resume;
- freeze receipts, schema meaning, policies, and incidents per issued artifact;
- replace loose schema discipline with one enforced registry;
- qualify a planner adapter instead of treating a matching JSON shape as model
  interchangeability;
- keep the fixed 1,680-label program out of the next release milestone;
- separate archive integrity from fresh source-based verification;
- keep the app shell and vendors outside the assurance boundary.

## Where They Disagreed

### Reader compatibility

Fable proposed that readers accept N and N+1. Sol rejected that rule because a
reader cannot understand a future required schema safely.

Decision: readers accept only exact supported schema IDs with matching schema
digests. Unknown required schemas return `unsupported`.

### Archive tiers

Fable proposed two tiers: archive-only integrity and RAW-backed
re-verification. Sol separated identity, historical attestation, fresh
re-verification, and project resumption.

Decision: four honest grades are used. The second grade is named
`historical_record` because the current reader does not verify an outside
signature anchor.

### Integer timing

Fable argued that integer frame indices freeze the current 30 fps CFR method at
the wrong layer. Sol required both rational timebases and source frame/sample
mapping.

Decision: the permanent rule is integer positions on a declared rational grid.
The source map preserves frame ordinals, timestamps, durations, and audio
sample indices. The 30 fps and 48 kHz implementation remains valid for current
receipts.

### Semantic timing

Fable proposed passive label capture from real edits. Sol proposed a smaller
decision-based study and warned against making every feature a required
receipt.

Decision: semantic promotion stays disabled. The 1,680-label build is parked.
Future research starts with consented local accept, reject, and re-edit reasons,
then measures the real class distribution. A later sealed qualification remains
separate from development data.

### Trust in the Law package

Sol warned that deterministic code can enforce a wrong rule. Fable warned that
schemas without prose meaning cannot be reimplemented.

Decision: the Python package is one reference reader. Hash-locked schemas,
written semantics, policies, and conformance fixtures define the contract.

## Additions Accepted From Fable

- RAW preservation is item zero.
- A resumption archive carries draft state, approved intent, fonts, and source.
- Planner qualification covers distributional behavior, not import wiring.
- Incident fixtures carry the incident story.
- Human exceptions carry signer identity and scope.
- Archive work comes before expanding cross-platform CI.

## Additions Accepted From Sol

- RAW is provenance, not assumed perfect sync truth.
- The transcript and its word timing are model assertions that need source
  anchoring and correction provenance.
- Capability, check, algorithm, payload, policy, and artifact-contract IDs are
  separate.
- `*.UNVERIFIED` is a safety affordance. The manifest and receipt chain carry
  the lasting evidence.
- A packed public key cannot authenticate its own archive. Stronger attestation
  needs an outside trust anchor.
- Bit-identical rendering, decoded-media equivalence, faithful re-verification,
  and project resumption are different promises.

## Usage Research Finding

No real installed-app usage study has been completed. The repository contains
an 82-decision model screen, one installed-app acceptance loop, one 0.1.5 smoke,
and the label/qualification tooling. `docs/SEMANTIC_VISUAL_BLOCKED.md` states
that the corpus is still zero. There are no non-test semantic label records,
organic edit-decision logs, interviews, or longitudinal cohort evidence in the
tree.

The executable result is in `autoeditor_law/`, the compatibility fixture is in
`compatibility/archives/2026-identity/`, and the binding contract is
`docs/AUTOEDITOR_2034_CONTRACT.md`.
