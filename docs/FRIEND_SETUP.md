# Ryan Reels Editor: Shorts Setup

Windows: download the x64 `.exe` installer Omar sends you and double-click
it. The signed friend release installs without command-line setup. Acceptance
builds that are not signed can show Windows SmartScreen once, in which case
choose More info, then Run anyway.

Mac: download the DMG that matches Apple Silicon or Intel, drag Ryan Reels
Editor into Applications, and open it. An unnotarized acceptance build needs
one right-click, then Open.

Open Settings, paste your DeepSeek API key once (it is
stored in your system keychain, never in a plaintext file), then pick the
profile that matches the short:

- Ryan Duffy: relatable POV and premise-driven skits.
- Ryan Humes: friendship skits and ranked or list-style shorts.
- Shared Skit: two-person reels with both Ryans.

Drop in the raw clips in the order they should play. Review the transcript
the app generates, or paste the exact script. Add optional music or your own
extra footage, choose an output folder, then click Edit Reel.

Each Ryan profile forces the shorts pipeline, including 9:16 framing,
short-form pacing, captions, creator-specific visual direction, rendering,
and quality checks. When the edit passes every check, the MP4 appears in the
output folder. If the app says Needs Review, watch the output and fix or
re-run it before uploading.

Notes:
- The first run downloads the speech model (one time, a few minutes).
- Multiple clips dropped together are joined in the order you added them.
- Extra footage should be footage you want the editor to use in that short.
- Music: add your own file in Extras, or add trending audio inside
  Instagram after you upload. Commercial songs can't ship inside the app.
- Your footage never leaves your computer. The only network calls are the
  AI edit-planner (your DeepSeek key) and the one-time model download.

Getting a DeepSeek key: platform.deepseek.com -> API Keys -> Create. It
costs a few cents per edit.
