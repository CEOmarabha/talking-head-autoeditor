# Ryan Reels Editor: Setup

Download Ryan Reels Editor for Mac or Windows from the link Omar sends you
and install it. Open Settings, paste your DeepSeek API key once (it is
stored in your system keychain, never in files), and pick your editing
profile. Drop in your raw clips, review the transcript the app generates
(or paste your script), then click Edit Reel.

The app handles cutting, captions, reframing, graphics, sound, rendering,
and quality checks. When the edit passes every check, your upload-ready MP4
appears in the output folder. If a quality check fails, the app labels the
result Needs Review instead of presenting it as finished. Watch those
before uploading.

Notes:
- The first run downloads the speech model (one time, a few minutes).
- Multiple clips dropped together are joined in the order you added them.
- Music: add your own file in Extras, or add trending audio inside
  Instagram after you upload. Commercial songs can't ship inside the app.
- Your footage never leaves your computer. The only network calls are the
  AI edit-planner (your DeepSeek key) and the one-time model download.

Getting a DeepSeek key: platform.deepseek.com -> API Keys -> Create. It
costs a few cents per edit.
